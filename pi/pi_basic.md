# 树莓派 5：核心知识与功能概览

> 适用范围：亚博智能《树莓派 5》“快速上手”、第一章至第三章。本文保留日常使用和项目开发最重要的知识点，不逐字复述教程。以 Raspberry Pi OS（新版）为主要操作环境；亚博智能预装镜像、Ubuntu 与官方系统可能存在菜单和软件版本差异。

## 1. 树莓派 5 是什么？

Raspberry Pi 5（树莓派 5）是一台信用卡大小的**单板计算机（SBC）**。它可以安装 Linux 系统，连接显示器、键盘和鼠标，也可以不接屏幕，通过网络远程控制。

**主要用途：**

- **学习 Linux 和编程**：使用终端、Python、C/C++ 开发程序。
- **硬件控制**：通过 GPIO 连接按钮、LED、传感器、扩展板等。
- **物联网与自动化**：采集环境数据、控制设备、搭建轻量服务器。
- **图像与机器人项目**：连接摄像头，运行 OpenCV 等程序；复杂 AI 任务需要考虑内存和算力限制。

它与 Arduino、单片机最大的区别是：树莓派能运行完整操作系统，适合网络、图形、应用软件和多任务；但并非硬实时控制器。

## 2. 主要硬件与功能

| 硬件 | 主要功能 |
| --- | --- |
| 处理器 CPU | 2.4 GHz 四核 64 位 Arm Cortex-A76，负责执行操作系统和应用程序。 |
| 图形处理器 GPU | VideoCore VII，负责图形显示和多媒体处理。 |
| 内存 RAM | 提供 1GB、2GB、4GB、8GB、16GB 等版本；内存越大，同时运行多个程序越从容。 |
| microSD 卡槽 | 常用系统盘，用于存储操作系统、程序和数据。 |
| 2 个 USB 3.0 + 2 个 USB 2.0 | 连接键盘、鼠标、U 盘、USB 摄像头等。 |
| 2 个 micro-HDMI 接口 | 连接显示器，支持双路最高 4K 60Hz 输出（还取决于线材、显示器和配置）。 |
| 千兆以太网口 | 有线联网，通常更稳定，适合远程管理和服务部署。 |
| 双频 Wi-Fi 与蓝牙 5.0/BLE | 无线联网、连接蓝牙外设和低功耗蓝牙设备。 |
| 40 针 GPIO 排针 | 连接电子模块，实现输入、输出和常用硬件通信。 |
| 2 个 MIPI CSI/DSI 复用接口 | 连接兼容的摄像头或显示屏。 |
| PCIe 2.0 x1 接口 | 通过扩展板连接 NVMe SSD 等高速设备。 |
| USB-C 供电与电源按钮 | 为主板供电，以及手动开机/关机控制。 |

**重点理解：**CPU 决定运算能力，RAM 影响多任务和程序规模，存储设备保存数据，而 GPIO、USB、网络、MIPI、PCIe 决定能连接哪些外部设备。

**1GB 版本注意：**更适合 Linux 基础、网络服务和简单 GPIO 实验。亚博智能明确提示：较重的 AI、MediaPipe、Jupyter、ROS 可视化和仿真等任务可能因内存不足卡顿或崩溃。

## 3. 供电、散热与启动

### 3.1 供电

- **推荐**使用树莓派官方 27W USB-C 电源，提供约 **5.1V / 5A**。
- 使用只有 5V / 3A 输出能力的电源时，USB 外设供电能力可能受限，连接硬盘、摄像头时尤其明显。
- 不能只看充电器标称“30W”“65W”，还应确认它能否在**约 5V 档提供 5A**。
- 普通用户优先使用 USB-C 供电；通过 GPIO 供电需要额外的电源保护知识，不建议新手尝试。

### 3.2 散热

CPU 持续高负载运行时会发热。安装**主动式散热器（散热片 + 风扇）**有助于降低温度、减少因高温导致的性能下降。安装时注意散热器固定位置及风扇接头，避免短路。

### 3.3 启动与关机

常见启动流程：**写入系统 → 插入 microSD 卡 → 接上外设（可选）→ 连接电源 → 启动系统**。

正常关机建议执行：

```bash
sudo shutdown -h now
```

重启：

```bash
sudo reboot
```

**不要在系统读写存储卡时直接断电**，否则可能损坏文件系统。

## 4. 安装操作系统与磁盘扩容

### 4.1 常见系统

- **Raspberry Pi OS**：官方系统，基于 Debian Linux；GPIO、摄像头、官方工具和学习资料配套较完善，**最适合新手**。
- **Ubuntu**：适合已有 Ubuntu/Linux 经验，或者需要特定开发、服务器生态的项目；安装和驱动配置可能与官方教程不同。

Raspberry Pi OS 常见选择：带桌面的版本适合初学者；**Lite（无桌面）**更节省内存，适合 1GB 机型、SSH 和轻量服务器。新版 Raspberry Pi OS 已基于 Debian Trixie；旧教程的截图或部分命令可能不同。

### 4.2 系统安装步骤

1. 在电脑上下载并打开 **Raspberry Pi Imager**。
2. 选择 **Raspberry Pi 5** 和所需的操作系统。
3. 选择准备写入的 microSD 卡，注意写入会擦除卡内数据。
4. 在 Imager 中预设用户名、密码、Wi-Fi、地区及 SSH（特别适合无屏启动）。
5. 写入完成后，将卡插入树莓派并通电。

**亚博智能特别说明：**其“出厂镜像”可能针对 ROS/AI 视觉、大模型等不同课程做过定制。若需要完全复现厂商案例，应选用对应镜像，而不是默认认为所有案例都适合任何系统。

### 4.3 备份与扩容

建议在系统和开发环境配置完成后，使用镜像备份或克隆工具备份启动盘。换卡或重新刷机前先备份重要数据。

查看磁盘空间：

```bash
df -h
```

通常 Raspberry Pi OS 在首次启动时会自动扩展文件系统。若没有用满 SD 卡容量，可运行：

```bash
sudo raspi-config
```

在 **Advanced Options → Expand Filesystem** 中扩容，并按提示重启。**扩容前先备份重要数据。**

## 5. GPIO：树莓派连接硬件的关键

GPIO（通用输入输出引脚）允许树莓派与电子模块通信。例如：读取按钮状态、让 LED 闪烁、检测传感器、控制外部驱动板。

40 针排针主要包括：

- **电源引脚**：3.3V、5V 和 GND（地）。
- **通用 GPIO**：可配置为数字输入或输出。
- **通信引脚**：支持 I²C、SPI、UART 等协议。
- **PWM 功能**：通过脉宽调制控制 LED 亮度、向兼容电机/舵机驱动板提供控制信号等。

### 5.1 两种引脚编号

- **物理编号（BOARD）**：按排针位置计数，1～40。
- **BCM 编号**：按 GPIO 信号名称编号，例如 **GPIO17 对应物理第 11 针**。

查引脚图可以使用：

```bash
pinout
```

### 5.2 常用通信方式

| 接口 | 作用 | 典型应用 |
| --- | --- | --- |
| I²C | 两根主要信号线连接多个低速外设 | 温湿度传感器、OLED、RTC 模块 |
| SPI | 较高速的同步通信 | 屏幕、ADC 芯片、部分传感器 |
| UART | 通过 TX/RX 进行串口通信 | 单片机、GPS、调试设备 |
| PWM | 输出可调占空比的脉冲 | LED 调光、驱动板控制 |

**安全规则：普通 GPIO 信号是 3.3V，不能直接接入 5V 信号；GPIO 也不能直接驱动大电流电机。**连接电机、继电器或高电压模块时，应使用合适的驱动电路和电平转换。

## 6. 重要扩展接口（了解功能即可）

- **PCIe**：树莓派 5 提供 PCIe 2.0 x1 通道，通过合适的 M.2 HAT/适配板可以连接 NVMe SSD。它通常比 microSD 更适合高频读写项目，但需要单独购买兼容配件。
- **MIPI CSI/DSI**：用于连接排线摄像头或显示屏。树莓派 5 有两个复用接口，可支持兼容设备的灵活组合；接线前应断电，并确认排线及转接头规格。
- **UART 调试接口**：用于串口调试、检查启动信息；与 40 针排针上可复用的 UART 引脚不是同一个物理连接器。
- **RTC 实时时钟**：在合适的备用电池供电下，断开主电源后仍能维持时间，适用于离线计时和定时任务。
- **PoE+**：通过**额外的兼容 PoE+ HAT**可让网线同时传输数据和供电；树莓派 5 的网口本身不等于直接支持 PoE 供电。

## 7. 系统基础管理

### 7.1 更新系统

```bash
sudo apt update
sudo apt full-upgrade
```

`apt update` 更新软件包列表，`apt full-upgrade` 安装可用更新并处理依赖变化。重要项目升级前先备份；**跨 Debian 大版本升级不要仅靠这两条命令**。

### 7.2 raspi-config 与 config.txt

```bash
sudo raspi-config
```

`raspi-config` 是树莓派的常用配置工具，可用来调整地区、主机名、接口、启动和部分高级选项。

`/boot/firmware/config.txt` 是重要的**启动配置文件**，可设置设备树覆盖、部分硬件接口及显示相关参数。修改后通常需要重启；不要随意照搬旧版本教程中的参数。

### 7.3 常用查询命令

| 命令 | 功能 |
| --- | --- |
| `uname -a` | 查看内核信息 |
| `cat /etc/os-release` | 查看操作系统版本 |
| `free -h` | 查看内存占用 |
| `df -h` | 查看磁盘空间 |
| `top` | 查看进程及资源占用 |
| `vcgencmd measure_temp` | 查看主板处理器温度 |
| `hostname -I` | 查看设备 IP 地址 |

## 8. 网络、远程访问与传输文件

### 8.1 网络连接

树莓派可通过**网线**或 **Wi-Fi** 联网。固定部署和频繁传输数据时，网线通常更稳定。

终端查看网络：

```bash
ip addr
nmcli device status
```

扫描 Wi-Fi：

```bash
nmcli device wifi list
```

连接 Wi-Fi（按提示输入密码）：

```bash
sudo nmcli --ask device wifi connect "你的WiFi名称"
```

无线网络连接前应正确设置所在国家/地区。

### 8.2 SSH：远程命令行

SSH 适合在个人电脑上控制树莓派，不需要为树莓派连接显示器。先在 Imager 或 `raspi-config` 中开启 SSH，再从同一局域网中的电脑执行：

```bash
ssh 用户名@树莓派IP
```

**示例**（请换成自己的用户名和 IP）：

```bash
ssh myuser@192.168.1.100
```

注意：官方新装系统由用户设置账号，不应默认所有机器都使用 `pi` 作为用户名。使用厂商预装镜像后，应及时修改默认密码。

### 8.3 VNC：远程图形桌面

VNC 可以在另一台电脑上看到并操作树莓派桌面。适用于图形软件、教学和可视化应用。需在树莓派端开启 VNC 服务并使用兼容客户端；新版 Raspberry Pi OS 采用 Wayland/WayVNC，旧教程指定的客户端未必完全适用。

也可以了解 **Raspberry Pi Connect**，用于浏览器远程访问。

### 8.4 SCP：远程传文件

从自己的电脑上传文件到树莓派：

```bash
scp demo.py 用户名@树莓派IP:~/
```

从树莓派下载文件到当前电脑目录：

```bash
scp 用户名@树莓派IP:~/demo.py .
```

SCP 依赖 SSH。不要将 SSH/VNC 直接暴露到公网；跨网络访问优先考虑 VPN 等安全方案。

## 9. 显示、音频与摄像头

### 9.1 显示与音频

- 两个 micro-HDMI 接口可以连接显示器；分辨率、旋转和休眠等一般先在桌面显示设置中调整。
- 音频可通过 HDMI、USB 音频设备或蓝牙音频设备输出；树莓派 5 **没有传统的 3.5mm 模拟音频插孔**。
- 无显示器时可通过 SSH 管理；需要图形桌面再考虑 VNC。

### 9.2 USB 摄像头

USB 摄像头接线方便，常用于视频采集、OpenCV、远程监控等。

检查是否被系统识别：

```bash
lsusb
ls /dev/video*
```

如果是兼容 V4L2 的 USB 摄像头，可使用 `fswebcam` 或相应视频软件采集图像。**出现 `/dev/video*` 不代表一定能直接使用所有拍摄工具**，还需检查对应设备能力。

### 9.3 MIPI 摄像头

MIPI 摄像头通过专用排线连接，适合小型嵌入式视觉项目。使用兼容的 Raspberry Pi Camera Module 时，可尝试：

```bash
rpicam-hello --list-cameras
rpicam-still -o test.jpg
```

第一条列出可用摄像头，第二条拍摄照片。新版本 Raspberry Pi OS 主要使用 **`rpicam-*`** 命令，旧资料中的 `libcamera-*` / `raspistill` 不应直接照搬。某些第三方摄像头可能还需要设备树配置或厂商驱动。

## 10. 常见问题与使用建议

| 问题 | 优先排查 |
| --- | --- |
| 无法启动 | 电源、microSD 镜像、接口接触、启动指示灯 |
| 不定时重启/USB 设备断连 | 电源是否满足要求，外设是否耗电过大 |
| 系统卡顿 | `free -h`、`top`、CPU 温度及存储速度 |
| SSH 连接失败 | IP 地址、同一网络、SSH 是否启用、用户名和密码 |
| 摄像头无法识别 | 摄像头类型、排线方向、系统版本、驱动及连接方式 |
| SD 卡空间不足 | `df -h`、文件清理、扩容、升级存储设备 |

**建议学习顺序：**先完成系统安装和安全关机，再掌握 Linux 基础命令、联网与 SSH，接着学习 GPIO 和外设通信，最后尝试摄像头、OpenCV、PCIe SSD 或其他进阶项目。
