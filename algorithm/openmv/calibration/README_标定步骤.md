# OpenMV 相机内参标定操作（独立脚本，不修改项目已有代码）

**对应现有项目** `demo/src_openmv/main.py`，目前 `MATERIAL` 等模式使用 RGB565 + QVGA 320×240。以下脚本仅用于校准镜头，正式识别仍运行原 `main.py`。

## 物料准备

- OpenMV H7 Plus + 实际比赛用的镜头（不要临时更换/重新对焦）。
- microSD 卡（脚本默认 `/sdcard/calib`，若旧固件将 SD 卡挂载到根目录 `/`，需调整 `SAVE_DIR`，且**确认没有误写到内置 flash**）。
- 打印附件 `chessboard_9x6_20mm_A4.pdf`：A4 横向、100% 原始尺寸、不要适应页面/缩放、不要双面；打印后用尺检查格边为 20 mm。贴在硬板上保持平整。
- PC 上 Python3 + OpenCV: `python -m pip install numpy opencv-python`。

## 采集图像

1. 在 OpenMV IDE 临时运行 `01_openmv_capture.py`（**不要把原 `main.py` 改名或覆盖**）。
2. 让整张棋盘始终在画面内，清晰对焦，光线均匀。每张之间换位置和角度，覆盖中间、四角、较近/较远、不同倾斜方向（不要大到棋盘变模糊）。
3. 脚本每 2.5 秒自动保存一张到 microSD，预设 35 张。取出 SD 卡，把图片复制到本目录 `images/`。剔除严重模糊、过曝的照片。
4. 采集的图片务必是 **320×240 未去畸变的原始图像**，与正式识别一致，不要先调用 `lens_corr()` 或裁剪。不要启用数字变焦。

## PC 求出 fx,fy,cx,cy

在 `demo/calibration/` 下执行：

```shell
python 02_calibrate_pc.py --images images --square-mm 20
```

`--square-mm` 必须是**打印后实际测量**的格宽。脚本检查 **9×6 个内角点**（实际 10×7 个方格），至少需 15 张可识别照片，推荐 20–35 张有差异的姿态。输出 `camera_intrinsics.json`、终端打印内参，另给出径向/切向畸变系数和重投影 RMS。

## 回填原项目（不换名字）

只修改 `demo/src_openmv/config.py` 里已有的配置：

```python
FX_PX = 你的 fx
FY_PX = 你的 fy
CX_PX = 你的 cx
CY_PX = 你的 cy
TOP_FACE_DIAMETER_MM = {1: 红色实际顶部直径, ...}
```

真实顶部直径必须使用卡尺测量，**不是随便填 40 mm**；六种颜色可能对应不同物料大小，需要逐一填写。

**重要：** 目前 `utils.py -> metric_from_circle()` 使用简化针孔模型，**没有真正用到畸变系数，也没有做倾斜平面姿态补偿**。只填四个参数和目标物理尺寸，程序会从 `valid=0` 变成 `valid=1`，但这只是数值条件通过，**不是精度达标证明**。镜头边缘的物料、倾斜的圆面必须进一步矫正后才能用于精准夹取。

## 距离实测验收

把物料顶部圆面尽可能正对镜头，放在图像中间（先降低畸变影响），用直尺/卡尺定位**相机光心到物料顶部圆面中心所在平面沿光轴方向的距离 Z**，分别在适合你实际工作范围的三个或更多距离记录 30 帧：

- 核对 `Z_mm` 与沿光轴的实测距离，不要把 `distance_mm`（斜距）与正对量尺的深度混淆；
- 查看 `diameter_px`、`u,v` 是否与真实物料边缘相符；
- 以中位数统计测距误差，首轮建议将 ±10% 当作调试目标，不代表比赛精度要求；
- 还要做画面边缘和倾角验收。如果差距很大，优先检查**顶部被跟踪圆面的尺寸、成像倾斜、镜头畸变、实际光心的量距基准、是否改变对焦/分辨率**。

色环 `RING_TRACKED_DIAMETER_MM` 也应按**跟踪到的那一圈真实直径**另外标定，不能直接沿用物料直径。

正式上板前，不要因为校准参数已回填，就认为整套机器人夹取控制具备闭环精度。
