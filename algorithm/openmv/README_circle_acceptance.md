# demo_circle：圆心与距离验收

本次修改 `demo_circle.py`，它仍可单文件运行。保留原来的六色 LAB 阈值、最大色块优先、霍夫圆、卡尔曼跟踪和实验性数字识别。其他原始 demo 与 `src_openmv` 文件未修改。本包另附电脑端回归测试和测试报告。

## 1. 上板运行

1. 用 OpenMV IDE 连接原项目指定的 **H7 Plus / v5.0.0**，打开本包的 `demo_circle.py` 并运行；不需要复制 tests 文件夹到板子。
2. 文件顶部 `TARGET_LABEL=1` 默认测试红色；2 黄、3 蓝、4 绿、5 黑、6 浅蓝，0 同时测试六色。首次验收先只测一种颜色。同色多目标仍只选最大色块。
3. 在 IDE 图像窗口看圆心十字及圆轮廓，在终端看每行 JSON。红色十字是原始候选，绿色是已确认跟踪，黄色是待确认或短时预测。数值显示在终端，沿用原版不使用 `draw_string` 的做法。
4. 连续 3 帧有效测量后发布坐标和距离。默认输出间隔至少 200 ms，实际频率受识别耗时影响，不承诺 5 FPS。
5. 该 demo 使用 IDE/USB 终端输出，不向 STM32 UART 发数据，不改变原有下位机协议。

## 2. 数据接口

`build_report(label, tracked, width, height, now_ms, digit=None, score=0.0)` 返回字典；主循环通过 `print(json.dumps(report))` 输出。接收端只解析以 `{` 开头的行，忽略启动及错误日志。

| 字段 | 含义 |
|---|---|
| `cx`, `cy` | 滤波后的圆心，整数像素；左上角 (0,0)，x 向右、y 向下；QVGA 范围 x=0..319、y=0..239 |
| `distance_mm` | 相机光心到色环圆心的估算直线距离，mm，保留 1 位小数 |
| `depth_mm` | 圆心沿相机光轴方向的深度 Z，mm；不是直线距离的别名 |
| `diameter_px` | 滤波后外圆直径，px，用于标定；测距内部使用未取整的半径 |
| `valid` | 本帧圆心已确认，且距离能按当前参数计算；**不代表已标定或已经达到测量精度** |
| `center_valid`, `distance_valid` | 圆心与距离分别是否可用 |
| `calibrated` | 显式配置 `DISTANCE_CALIBRATED` 的值；程序不会自动认定标定完成 |
| `distance_status` | `REFERENCE` 为未标定参考值；`CALIBRATED` 为已手动标记标定；`BAD_CONFIG` 为尺寸/焦距/分辨率等不合法；其他情况下跟随跟踪状态 |
| `status` | `NO_TARGET` 无可靠跟踪，`WARMUP` 未连续确认，`CONFIRMED` 已确认，`PREDICT` 当前无被接纳的测量 |
| `label`, `timestamp_ms` | 颜色编号、板端毫秒 tick（会回绕，不是日期时间） |
| `digit`, `digit_score` | 保留原版实验性数字识别；与颜色编号是两个概念，不作为距离有效条件 |

以下是计算示例，**不是实拍结果**：参考外径 80 mm、焦距 225 px，圆心 (160,120)、外圆直径 60 px。

```json
{"type":"RING","label":1,"timestamp_ms":1000,"status":"CONFIRMED","valid":true,"center_valid":true,"distance_valid":true,"calibrated":false,"cx":160,"cy":120,"diameter_px":60.0,"distance_mm":300.0,"depth_mm":300.0,"distance_status":"REFERENCE","digit":null,"digit_score":0.0}
```

`WARMUP`、`PREDICT`、`NO_TARGET` 的 `valid=false`，`cx`、`cy`、`diameter_px`、`distance_mm`、`depth_mm` 全部为 `null`，不重发过期坐标。短时预测仅用于黄色画图，超过 5 帧丢失后清空跟踪；重新检测仍需连续 3 帧确认。异常焦距/外径/分辨率下可以保留已确认的圆心，但距离为 `null`。

若用于后续控制，请要求 `valid && calibrated`，并在接收端自行设置通信超时。当前位置是图像坐标，不是小车坐标系或机械臂坐标系。

## 3. 测距模型与标定

沿用项目配置中的 **80 mm 外径、225 px 焦距**，这些是参考值，绝不能直接当作实机标定结果。

测距假设：色环平面近似平行于成像平面、目标完整可见、水平与竖直像素焦距近似相等、镜头畸变较小。计算式：

```text
Z = FOCAL_PX * RING_REAL_D_MM / diameter_px
X = (cx - principal_x) * Z / FOCAL_PX
Y = (cy - principal_y) * Z / FOCAL_PX
distance_mm = sqrt(X*X + Y*Y + Z*Z)
```

`principal_x/y` 默认 (160,120)，可用 `PRINCIPAL_X_PX` / `PRINCIPAL_Y_PX` 填写标定主点。色环偏离画面中心时，直线距离会大于深度；对准主点时二者相等。这是光心到目标的距离，不是摄像头外壳到目标的间距。

单点标定步骤：

1. 实测色环**外径**，写入 `RING_REAL_D_MM`；六种颜色在当前实现中共用此外径。若现场尺寸不同，一次测一种并改对应外径。
2. 固定镜头、焦距、分辨率、曝光环境，让环面正对相机并使圆心对准画面主点。先确认绿色外圆跟随的是外边缘。
3. 放到已知光轴深度 `Z_known_mm`，固定不动，等待滤波稳定（建议 3 秒），记录至少 30 个有效 `diameter_px`，取中位数 `d_px`。
4. 计算 `FOCAL_PX = Z_known_mm * d_px / RING_REAL_D_MM`，修改常量并重启。例如 300 mm、外径 80 mm、直径 60 px，对应 225 px；这是演示算例。
5. 在另外两个深度检查误差；验证满足自己的标准后才设置 `DISTANCE_CALIBRATED=True`。该开关只声明状态，不会改善精度。
6. 改分辨率、裁剪、镜头或焦距后重新标定。当前分辨率检查要求 320×240；不要只改检查常量而不重新标定。

若光心位置难以准确定位，保持量尺参考点一致并记录其与光心的偏移，近距离验收尤其要留意该系统误差。

**斜视限制：** 将摄像头明显斜向下看地面色环时，投影是椭圆。此版会拒绝外接框长短比小于 0.90 的样本，但这个筛选不是姿态估计，不能保证所有倾斜样本都被排除。此模型不能宣称支持任意倾角。明显斜视场景需另外做平面标定/椭圆姿态解算；强畸变、严重遮挡、同色干扰也需要实拍调试。未标定时仍输出参考距离，并明确标记 `REFERENCE`。

## 4. 本次针对测距的修正

- 霍夫圆半径合并门限从 10 降为 2 px，减少内外边缘被合并；不再把内圆、外圆半径取平均。
- 选择与色块外接框四边最吻合的圆作为外圆。找不到匹配外轮廓时，只显示低置信候选，不发布距离。
- 截边和明显椭圆样本不给可靠测量；位置及半径均做卡尔曼创新门控。
- 距离使用浮点滤波半径，避免先把半径取整造成额外台阶。
- 六色模式先完成所有识别再绘图，避免前一种颜色的十字标记干扰下一种颜色识别。

这些筛选仍属于原有 LAB＋霍夫方法，不能保证所有同色实心圆、非环物体或背景干扰都被排除；现场应验证实际目标与背景。若只有红色候选、没有绿色确认，先检查颜色阈值、外轮廓完整性、环面角度及霍夫阈值，不要直接把低置信样本当作可测距目标。

## 5. 上板验收表（待实测）

以下是建议的首轮工程验收条件，不是已测得的指标，也不是硬件精度承诺。

| 测试 | 操作 | 预期与记录 |
|---|---|---|
| 坐标方向 | 让色环向右/向下移动 | cx / cy 分别增大，绿色十字落在圆心附近 |
| 圆心稳定 | 正对、静止 3 秒后取 30 个有效样本 | 建议各轴峰峰抖动 ≤5 px，记录实测值 |
| 距离精度 | 标定后在约 200 / 300 / 400 mm 正对测试，完整入镜 | 每处稳定后取 30 个样本，用中位数与量尺比；首轮目标误差 ≤10%，不达标须继续标定/调参 |
| 远近变化 | 缓慢远离再靠近 | 远离时外圆直径减小、距离增大；快速运动时允许短暂未确认 |
| 偏轴距离 | 环面保持平行，固定深度向左右平移 | depth_mm 近似不变，distance_mm 随偏轴增加 |
| 丢失 | 完全移走色环 | 下一次输出为无效、坐标与距离 null；5 帧预测后清空 |
| 重捕获 | 再移回画面 | 连续 3 帧通过才恢复有效数据 |
| 截边/倾斜 | 让环超出画面或显著倾斜 | 不应持续返回有效距离；轻微倾斜仍可能通过，需要记录误差 |
| 六色独立 | TARGET_LABEL=0，摆放多种颜色 | 每个标签独立报告；无目标的标签有明确无效状态 |
| 数字功能 | 在原有 1/2/3 模板适用样本上测试 | 保留识别结果；数字识别失败不阻断圆心与距离 |

建议记录：真实外径、镜头/分辨率、FOCAL_PX、照明、量尺深度、输出距离中位数、误差%、圆心抖动、有效帧比例、实际输出频率。测试时可以先 `ENABLE_DIGIT=False`，专门验收圆心与距离，再恢复原版数字识别。
