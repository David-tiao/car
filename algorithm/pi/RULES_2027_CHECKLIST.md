## 规则硬门槛

| 类别 | 规则重点 | 对应工程检查 |
|---|---|---|
| 外形 | **出发前**机器人含机械臂、线束的铅垂投影 ≤300×300mm，高度 ≤400mm；折叠机械臂出发后才可自主展开，展开后上述尺寸限制例外 | 实物最大包络尺寸、线束绕转、折叠/展开时序；不以网页模型代替测量 |
| 电源 | 只能使用一个安装在机器人内部的电源，含调试期间不能更换 | 电源检查、负载电流、保险/急停、供电时长；Pi5+雷达+屏幕+电机都要计入 |
| 显示 | 机身上部醒目位置亮光显示任务码及完成信息，**字高≥12mm**、无遮挡 | 真实显示器可读性/亮度/字符尺寸；二维码读到后显示任务码，结束后显示抓取/放置正确数 |
| 补光 | 不能遮挡场地，**只能垂直向下补光** | 相机补光方向、反光、转盘背光排查；不得假定随意斜向补光合法 |
| 控制 | 机器人完全自主；比赛中允许与笔记本通信，但运行期间不能触摸电脑，不得采用任何遥控方式 | 一键启动后禁用 VNC/SSH/C2 人工下达动作、网页键盘和 PC teleop；设备管理不成为运动控制来源 |
| 尺寸/材料 | 非标机械零件需自主设计制造；比赛中不得更换零部件 | BOM、CAD、加工与替换件记录；现场材料确认 |

## 场地、物料、二维码

- 场地 **2400×2400mm**；离开启停区后底盘铅垂投影只能处于灰色车道，跨入其它颜色区域（机械臂例外）导致该轮结束。中间十字灰色车道宽 **400mm**，四个淡黄色区各 **450×450mm**。不能只检查机器人中心点，需考虑底盘实际投影、定位误差和安全裕量。
- 两处启停区，单区 **300×300mm**；黑色随机路障约 **Φ50×100mm**。原料区、二维码板位置存在随机/安装偏差，不可把固定演示坐标当实测。
- 原料区圆盘直径 **300mm**、总高度约 **80–100mm**；三件物料均匀布置，位置角间距 **120°**，圆周直径约 **200mm**；转盘约 **6–10 秒/圈**并有停留。
- 暂存区和粗加工区各 **580×150mm**，包含标记数字的三工位/同心圆环。物料颜色红(1)、黄(2)、蓝(3)、绿(4)、黑(5)、浅蓝(6)，每色两件；初赛颜色有色差、需现场校准。单件材料 ABS/PLA、尺寸不超过80mm、重量不超过100g。
- 二维码板约 A4 横向放置、二维码本体 **80×80mm**（含边框）、位置在允许范围内随机。任务码四组三位数，如 `156+123+516+231`：
  - 第一组 = 第一批颜色与取料顺序；
  - 第二组 = 第一批粗加工区与暂存区对应圆环号；
  - 第三组 = 第二批颜色与取料顺序；
  - 第四组 = 第二批粗加工区对应圆环号；
  - 第二批到暂存区时，按**颜色相同**码垛在第一批的物料上，不要把第四组误当暂存区新环号。

## 比赛动作顺序（不可省略）

```text
一键启动 → 自动读取并显示任务码
→ 第一批三件按顺序逐件抓取并放到机器人承载区
→ 前往粗加工区按任务码放置 → 按规定顺序重新取回到机器人上
→ 前往暂存区按对应环号放置第一层
→ 返回原料区 → 第二批三件依次抓取并放车上
→ 粗加工区按第四组环号放置 / 取回
→ 暂存区按同色第一层码垛
→ 返回抽签的启停区 → 显示正确抓取数与正确放置数
```

**不允许用夹爪夹着物料跨区域运输**：物料必须先放到机器人车身承载区，才能前往下一区域。本区域内部的操作按原规则执行。物料底面碰地即记为放置完成，之后不能再推移纠偏或重新拖动该物料。

## 时间、终止与评分优先级

- 每队两轮，每轮**调试3分钟、运行3分钟**，取现场最好一轮；发令后**一键启动且只有一次启动机会**，不能触碰机器人、笔记本或物料。
- 机器人运行停止 **15秒** 即本轮结束（等待转盘转动时增加8秒，具体裁判解释为准）；代码要区分合法等待与故障停滞，不要用 UI 动画掩盖静止。
- 行驶越界、高速原地打滑、重新移动已经放置的物料、裁判禁止的人工介入，均有严重终止/取消成绩风险。
- 初赛总评：任务命题文档 20%，作品创意 10%，现场初赛 70%。现场抓对一件得 2 分；正确读取二维码并车载显示任务码得 1 分。
- 同心圆环**越靠内得分越高**：1/2/3/4/5/6 环分别 **15/10/7/5/3/1 分**，6 环外或倾倒为 0；第二批暂存区码垛需同色、第一层正确、物料不掉落。完成全流程回启停区得 2 分，正确显示抓取数与放置数各得 2 分。
- 文档需按组委会指定模板与匿名要求提交；不可把本工程 Markdown 直接作为正式匿名文档。

## 转为模块验收

- [ ] **ROS2 地图/导航**：车体外接矩形和定位裕量不能越灰色道路；真实障碍 `UNKNOWN` 不当作通行；成功锁路后固定可行路线。
- [ ] **视觉**：随机 QR 摆位、六色变化、旋转转盘与三环数字识别，图像检测必须有置信度/超时；不能依赖单个固定角度样本。
- [ ] **STM32**：一次启动、速度约束、急停和停滞计时、抓取/搬运/放置状态、回执与计数区分；无 ACK 或执行反馈不得提前推进 FSM。
- [ ] **显示**：任务码与最终正确数量来自真实事件，字号实测，掉线显示明确故障状态。
- [ ] **系统**：所有动作自主，比赛不使用 PC/网页远程驾驶；Pi/摄像头重启恢复不得跳过安全状态。
- [ ] **实机**：调试和比赛计时按真实场地执行，记录单轮完整耗时、越界、误抓/误放/事故、恢复与证据。
