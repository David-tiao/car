实车模式操作

① 打开服务器：car

② 第二个 Ubuntu 终端：cd ~/Downloads/competition_simulator_server && bash start_ros_bridge.sh

③ 确保 ROS2 发布真实 /odom，网页显示 vx、vy、wz、位置、航向与黄色实际轨迹。

如果只有 /cmd_vel 而没有实测 /odom，不能当作实车反馈；这里仅做监视，不控制电机。
09 / CAMERAS

实车双路相机

实车模式才会开启视频显示。OpenMV 使用 USB 虚拟串口，树莓派 5 使用 Picamera2。

OpenMV H7 Plus未连接OpenMV 端拍 JPEG，Ubuntu 端通过 USB 接收后上传；请注意原有颜色识别程序需要合并，不能直接覆盖。
Raspberry Pi 5 · 77°未连接在树莓派运行 Picamera2 采集程序，传输到 Ubuntu HTTP 网站。77° 是镜头视角，不是软件裁切参数。

Ubuntu 启动网站：car
OpenMV 读取：bash start_openmv_camera.sh
树莓派采集：python3 pi5_camera_sender.py --server http://UBUNTU-IP:8080 --token TOKEN

服务器上的 data/camera_token.txt 用于摄像头上传鉴权，不会发给网页访问者。两路画面是监控视频，尚未自动输出识别结果或指令。
