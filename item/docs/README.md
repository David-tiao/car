# 项目总览与历史记录索引

5. [故障原因、修复和经验](../../docs/ISSUES_AND_LESSONS.md)——包括 Git rebase、网页不动、视觉协议、机械轴误解、CI 失败。
6. [下一步联调计划与验收](../../docs/ROADMAP_AND_ACCEPTANCE.md)——如何逐阶段真正对上电控和机械。

项目管理可以继续在本目录记录原始问题和当天进度；技术结论与统一架构以根 `docs/` 为主，避免两套维护中互相冲突。
