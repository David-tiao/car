# 本文件主要是总结一下我们从创建之初遇到的错误
核心:我们应该搭建我们自己的工作流

参考:我写的AI开发规范文档

第一个错误:
没有一开始看清楚比赛规则,导致我们一开始的硬件没有确定,急急忙忙的,我们应当花大量时间先去看规则,然后选择自己要的东西
阅读清楚规则


第二个错误:
板子烧坏了---安全用电,学一点EDA板子的知识
安全用电


第三个错误:
一定要多去反思,多次修改!多次测试!写好之后一次次完善以后再测试完,自己在去看代码(把自己的注意力放到应该有的地方)


第四个错误:
一定要同步到github上,不管什么项目,好管理,而且chatgpt也能访问,很方便


第五个错误:
应该一开始把文件结构写清楚,这样到github上方便---也应当学会创建新的分支
合并的脚本需要写好(多人合作的时候)  --- 可以参考我们写的脚本模板,但是这个模板很显然还是没写分支的创建与处理
**我们需要构思一个合格的github的脚本**


第六个错误:
通行协议没有过早规范好,这一部分需要和电控实时商量
这里我们可以将通行协议拆分为**物理量协议,控制协议,反馈协议,系统事件**


第七个错误:
规划好每天要处理什么事情,而不是每天都无所事实一样
